# Reequipamiento-de-maquinaria-convencional

Este repositorio contiene el firmware en Arduino IDE para un Módulo de Retrofitting Universal (MQL) basado en ESP32. El sistema automatiza la refrigeración en maquinaria convencional al detectar en tiempo real el esfuerzo de corte mediante un sensor de corriente SCT-013 y un ADC de 16 bits ADS1115.El código implementa un cálculo de corriente RMS y una función de tara instantánea por botón, lo que permite fijar el "cero" del motor en vacío de inmediato. Gracias a la alta resolución del ADC, el sistema es altamente sensible a cambios leves de corriente ($0.15~A$), activando de forma síncrona un transductor humidificador ultrasónico mediante un MOSFET (IRLZ44N) con diodo flyback. El estado del sistema y la telemetría se despliegan en tiempo real en una pantalla OLED de 0.96" vía I2C.
